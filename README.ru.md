## Что такое MacroCode?

MacroCode — кроссплатформенное настольное приложение с открытым исходным кодом,
позволяющее общаться и работать с моделями ИИ через **интерфейс в стиле терминала,
используя собственные API-ключи** (BYOK). Написано на Tauri v2 + React + TypeScript,
распространяется как один компактный нативный бинарник и создано для разработчиков,
которым по душе текст, команды и горячие клавиши.

Без сервера, без аккаунта, без телеметрии: ваши диалоги хранятся в локальной базе
SQLite, а ключи покидают ваш компьютер только в виде заголовков аутентификации,
отправляемых непосредственно выбранному провайдеру.

## Что умеет?

- **Чат с 7 провайдерами** — Anthropic, OpenAI, Google Gemini, Ollama, OpenRouter,
  DeepSeek и xAI. Провайдер появляется в списках только после ввода его ключа
  (для Ollama — локального URL).
- **Сотни моделей на выбор** — небольшой курируемый каталог обогащается метаданными
  [models.dev](https://models.dev): лимиты контекста, поддержка изображений/рассуждений
  и цены.
- **Работа как в терминале** — слэш-команды (`/model`, `/tokens`, `/compact`, `/help`…),
  история сообщений по `↑ ↓`, мгновенный подсчёт токенов за каждую итерацию.
- **Режим агента** — укажите папку проекта через `/root`: он может читать файлы, искать
  по коду, редактировать файлы и выполнять команды shell. Каждая запись/выполнение
  проходит через карту подтверждения, которую можно принять или отклонить; `rm`
  ограничен, системные папки заблокированы. Дополнительно подключаются MCP-серверы
  (stdio или HTTP) — для дополнительных инструментов.
- **Контроль затрат** — кэширование промптов (брейкпоинты Anthropic / ключи кэша,
  совместимые с OpenAI) удешевляет длинные сессии; `/tokens` показывает точную стоимость
  каждой итерации, включая чтения кэша.
- **На вашем языке** — интерфейс полностью переведён на Deutsch, English, Español,
  Français и Türkçe; переключение применяется мгновенно, без перезапуска.
- **Ваши данные остаются у вас** — сессии живут в SQLite с экспортом/импортом JSON;
  всё переносимо и при необходимости работает офлайн.

## Установка

Скачайте пакет для своей платформы на странице
[Releases](https://github.com/Geblkc/Macro-Code/releases)
(Linux `.deb` / `.AppImage`, Windows `.msi` / `.exe`, macOS `.dmg`).

Или соберите из исходников:

```bash
npm install
npm run tauri dev    # полнофункциональное настольное приложение (нужны Rust и зависимости Tauri)
npm test             # модульные тесты
```

## Первый запуск

1. Откройте **Настройки** (или введите `/key`).
2. Вставьте API-ключ вашего провайдера и сохраните. Для [Ollama](https://ollama.com)
   достаточно локального URL, например `http://localhost:11434`.
3. Введите сообщение — или `/help`, чтобы увидеть все команды.
