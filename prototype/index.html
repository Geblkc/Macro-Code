Sorun: MessageLine her delta'da replaceChildren + appendChild çağırıyor.
Tam mesaj yeniden kuruluyor → O(n²) DOM işi + metin zıplaması.

Çözüm adayları:
  1. Blok bazlı artımlı render (son blok sadece)
  2. React.memo ile tamamlanmış mesajları dondurmak
  3. store tarafında hedefli güncelleme (updateLastMessage)

Asıl sorun DOM değil, render stratejisi

Şu an MessageLine her delta geldiğinde tüm mesajı yeniden kuruyor. 2000 token'da bu, 2000 tam yeniden çizim demek.

Önerilen: artımlı blok render'ı

  1. Markdown çıktısını blok (paragraf/liste/kod) dizisine ayır.
  2. Her bloğu React bileşenine çevir; key = blok indeksi + hash.
  3. Yalnızca son blok (hala yazan) yeniden render edilir.
Sonuç: render maliyeti O(n²) → O(n). Uzun cevaplarda akıcılık farkı gözle görülür.

Referans implementasyon

1export function MarkdownStream({ blocks, tail }: Props) {
2  const frozen = useMemo(\n    () => blocks.slice(0, -1).map((b, i) => <Block key={i} { **b** />),\n    [blocks]\n  );
3  return (\n    <>\n      {frozen}\n      <Block key={"tail"}>{tail}</Block>\n    </>\n  );
4}
